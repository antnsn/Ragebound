# Commands

Everything in Ragebound can be set in the options window (`/rage`). These chat commands are shortcuts.

`/ragebound` works everywhere `/rage` does. Commands only do something on a warrior.

## Windows and help

| Command | What it does |
| --- | --- |
| `/rage` | Opens or closes the options window. `/rage options` and `/rage config` do the same. |
| `/rage help` | Lists every command in chat. |

## Frames

| Command | What it does |
| --- | --- |
| `/rage unlock` | Unlocks all frames so you can drag and resize them. See [Frames and minimap](features/frames-and-minimap.html). |
| `/rage lock` | Locks the frames again. |
| `/rage move` | Unlocks the frames, or locks them if they are unlocked. |
| `/rage reset` | Puts every frame back in its default place and size. |
| `/rage grid` | Turns snapping to the grid on or off. |
| `/rage grid 30` | Sets the grid size (4 to 100) and turns snapping on. |
| `/rage minimap` | Shows or hides the minimap button. |

## Tooltips

| Command | What it does |
| --- | --- |
| `/rage explain` | Turns the [explanations](features/explanations.html) in tooltips on or off. |

Each command also works without the space, for example `/rageunlock` or `/ragereset`. That helps with chat setups that swallow the Enter key after a space.

Type anything else after `/rage` to get the list of commands in chat.

The [buff key](features/buff-key.html) is not a command: set it on the **Extras** page of `/rage`.
